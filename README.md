# Blinkit-Sales-Dashboard
Power BI dashboard analyzing Blinkit grocery sales data across outlet types, locations, and item categories.
Built in Power BI using Blinkit grocery sales data. This dashboard analyzes total sales ($1.20M), average sales, number of items, and average ratings across outlet types, sizes, and locations. Includes DAX measures, slicers for dynamic filtering, and visualizations for fat content, item type breakdown, and outlet establishment trends.
